Install

  1. Download the .apk file from the build you want.

  2. If the build shows a SHA-256 hash, compare it with the hash of the file you downloaded.

  3. Open the file. When Android asks, allow installs from the app you opened it with.

  4. Tap Install.

Add a build

Host the .apk on GitHub Releases, Google Drive or similar, then paste the direct link. Links must start with https://.
